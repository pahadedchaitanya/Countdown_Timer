# Countdown Timer

This is a simple command-line countdown timer written in C.  
You can enter the time in hours, minutes, and seconds — and it counts down in real-time.

---

## 📌 Features

- Accepts user input for hours, minutes, and seconds
- Validates input (hours: 0–99, minutes & seconds: 0–59)
- Displays countdown in HH:MM:SS format
- Uses sleep() to delay 1 second between updates
- Perfect for practicing basic loops and time handling in C
